云图科技 · 一体化靶场  v1.1
========================================

这是一个本地安全训练环境（靶场）。双击运行后，浏览器会打开一个
无地址栏的客户端窗口，里面是关卡列表和攻击控制台。

不需要安装 Node.js，不需要数据库，不需要联网。


一、怎么开始
----------------------------------------
1. 双击「启动靶场.bat」
   - 会启动 靶场.exe，并打开客户端窗口
   - 也可以直接双击「靶场.exe」，然后手动访问 http://127.0.0.1:7788/

2. 在控制台左侧选一关，点「目标入口」去攻击
3. 找到 flag 后回来提交，自动计分

三个入口：
   攻击控制台   http://127.0.0.1:7788/
   靶标业务站   http://127.0.0.1:7788/lab
   靶标 HTTPS   https://127.0.0.1:7789/lab     自签证书
   主机终端     nc 127.0.0.1 2222              ops / Cloud@2024


二、数据在哪
----------------------------------------
所有进度都在 exe 同目录的 data\ 文件夹里（state.json）。
   - 想重开一局：控制台右上角「重置靶场」，或直接删掉 data\state.json
   - 想备份进度：复制 data\state.json
   - 想分发给别人：删掉 data\ 再打包


三、想被抓包 / 被扫描
----------------------------------------
控制台右上角有「抓包 / 扫描」按钮，里面列了 Burp 配置和可复制的
nmap / dirsearch / nikto / sqlmap 命令。

关键一点：Chrome 走系统代理时会默认绕过 127.0.0.1，必须这样启动：

  chrome.exe --proxy-server="127.0.0.1:8080" --proxy-bypass-list="<-loopback>"

否则 Burp 里什么都看不到。

想让 SSRF 的服务端请求也进 Burp：
  set RANGE_UPSTREAM_PROXY=http://127.0.0.1:8080
  然后重新双击 靶场.exe


四、常驻运行
----------------------------------------
双击「服务管理.bat」，可以：
   1  开机自启（当前用户，免管理员）
   2  注册为系统服务（开机即运行，需要右键"以管理员身份运行"）
   3  立即停止
   4  查看状态
   5  卸载全部自启配置


五、注意
----------------------------------------
这是一台故意留有漏洞的机器。默认只监听 127.0.0.1，
请不要把它暴露到公网。
